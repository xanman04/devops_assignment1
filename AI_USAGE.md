This log is organised **per commit**. Each row describes the AI-assisted work that one commit contains, however many prompts that took. The assignment's own wording asks for one row per meaningful interaction, so this is a grouping of those interactions, not a replacement for them: the prompt-by-prompt notes that used to be here have been condensed into the rows below, and the earlier version of this file remains available in the Git history.

How the rows were built: commits and dates come from `git log`; the tool comes from the commit's `Co-Authored-By: Claude` line where present, and otherwise from the earlier log; requests, dispositions and "what changed" come from the earlier log entries and the commit contents. A request is in quotation marks only where the earlier log recorded the author's exact words; otherwise it is a summary. **Disposition** is filled in only where the earlier log states it. Everywhere else it says "Not recorded; author to confirm", and nothing has been guessed. **In my own words** is the author's own column, written by the author using real function and variable names.
