# Curated DJ sources and photo credits

The seven DJ profiles are real artists, separate from the fictional Madrid event fixtures. Their broad genre associations are editorial starting points, not claims that every set fits only those categories. The `seed_djs` command uses existing admin-managed genres and skips a profile if a required category is missing.

Bundled thumbnails in `static/djs/` were resized and converted to WebP from Wikimedia Commons originals. Each DJ page links its photo source and names the photographer and license. These credits should remain with the images if the project is reused.

Photo names, licenses, and source URLs are also stored on each `DJProfile`. Run `python tools/fetch_dj_photos.py` only when deliberately refreshing the bundled thumbnails; check the Commons source and license again before replacing any file.

Each profile page lists its most-listened songs and its past sets or mixes, roughly most popular first. Carl Cox is treated as a DJ only, so his page lists sets without a songs column; the other six have both. The links are in `discovery/management/commands/_dj_media.py`. They point to uploads on the artist's, label's, promoter's or broadcaster's own channels (for example the artist, Boiler Room, Cercle, Tomorrowland, Awakenings, Mixmag, DJ Mag, Ultra Records, UKF), on YouTube or SoundCloud. They were gathered from YouTube search results on October 1, 2026, with order following the view counts shown then, and each link was checked against the platform's oEmbed endpoint for an existing, matching title. Bassline stores URLs and titles only; it does not copy or embed the audio. Videos can be removed or made private later, so recheck the links before relying on them.

`seed_djs` adds any missing link once. It owns the order of the links it lists, so rerunning it restores that order, but it never changes a link's title or other fields and never touches links a curator added in admin.

Profile facts (hometown, start year, labels) and the Instagram, YouTube, SoundCloud and Spotify profile links come from Wikidata, queried October 1, 2026, and every profile URL was checked to resolve. They are stored in `discovery/management/commands/_dj_profiles.py`. `seed_djs` fills a fact only while it is blank and adds a social link only when that platform is missing, so admin edits are never overwritten. Labels are a short editorial selection, not a complete discography. Start years follow Wikidata and may differ from other sources.

## Genre and subgenre songs

`discovery/management/commands/_genre_songs.py` lists 439 representative songs: at least three per broad genre and at least one for each of the 251 subgenres (183 have two). Each entry says which genre, or which subgenre, it represents. Candidates were chosen by hand for each style, then looked up on YouTube; a match was kept only if the upload's title and channel contained the song and artist, and it was not a cover, remix, lyric edit, slowed version or mashup. All 439 links were then checked against YouTube's oEmbed endpoint. Where a very small style (for example raptor house or hard drum) has almost no released tracks on YouTube, 21 entries are DJ sets or mixes from the scene's own DJs or from Boiler Room, marked as sets. Several subgenres in niche styles rely on community uploads, which can disappear; recheck before relying on any single link. Bassline stores the URL, title and artist only and never copies or embeds audio. `seed_genre_songs` adds missing songs and extra genre links and never edits or removes existing ones.
